Pourquoi le code s'affiche-t-il dans Hostinger Webmail ?

Si vous collez du code HTML brut (avec des balises comme <table>) directement dans la zone de texte, le webmail le lit comme du texte simple.

Comment faire en 2 secondes :
  1. Cliquez sur le bouton bleu « Copier la signature visuelle » ci-dessous.
  2. Ouvrez votre webmail Hostinger : Paramètres > Identités (ou Signatures).
  3. Cochez bien la case « Signature HTML » si vous utilisez Roundcube.
  4. Cliquez dans la zone de texte et faites simplement Coller (Cmd + V ou Ctrl + V) !
